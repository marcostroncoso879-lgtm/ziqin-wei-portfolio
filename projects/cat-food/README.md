# 爱猫如爱人 · 每日食物计算器

文献与产品依据见同目录 `evidence.html`：三篇定向检索论文注明核对层级，皇家、ORIJEN与ZIWI四款具体产品注明地区、官方能量与配料来源。核对日期2026-10-09。这些地区版本不能代替用户手头包装，配料排位不用于质量评分。

按包装标注的代谢能或对应熟肉的已知参考热量，将每天的能量目标换算为干粮、湿粮、鲜食克数。原生 HTML、CSS 和 JavaScript，无依赖、无 CDN、无构建步骤；直接打开同目录 `index.html` 即可离线使用（支持 file://）。

## 使用

1. 仅用于健康成年猫、理想体况、体重维护期。默认体重 4 kg，选择绝育状态，或输入已有 / 兽医给定的自定义 kcal/day 目标。
2. 填写单独的零食每日总 kcal；干粮与鲜食各填占“扣除零食后的餐食能量”的 0-100%，两者合计不能超过 100%。湿粮自动取剩余比例。比例不是克重比例，空白或无效比例不会按 0 处理。
3. 分别录入三类食品能量，独立选择 kcal/kg 或 kcal/100g。干湿粮及完整均衡鲜食使用包装代谢能；普通熟肉使用对应食物的已知参考热量。未参与配比的类别可留空；不按名称自动填写或估算。
4. 价格选填，单位为元/kg。空白表示未填写；只有参与配比的价格都有效才显示食物合计成本，包含干粮、湿粮、鲜食，不含单独填写的零食成本。30 天按同一日量和单价估算。
5. 显式点击计算后可复制每日方案；剪贴板受限时提供可手动选择的文本。任何输入变化都会使旧方案失效，需重新计算。手机端成功提交后定位到结果。
6. “填入演示数据”保留干粮 60%、湿粮 40%、鲜食 0% 的虚构示例，不代表真实产品或完整配方。一键重置将鲜食比例归 0、类型归完整均衡鲜食主食，清空鲜食字段和确认勾选，同时清空干物质工具。

## 两种鲜食场景

- 完整均衡鲜食主食（complete）：仅指已由用户按包装确认适用成年猫维护期的完整均衡商业主食。实际参与配比时，页面要求勾选标签确认；工具不能核验产品真伪或完整营养。普通鸡肉、牛肉或其他食材不得直接归入此类。
- 普通熟肉加餐（topper）：例如熟鸡胸肉、熟牛肉等非完整主食，只计算已知热量，不设计自制完整配方。肉种、部位、生熟状态与烹调方式影响数值，不可套用或凭空估算；食物参考热量未必等同猫实际代谢能，所得克数是估算，页面和复制方案均注明。页面没有肉类热量表。其能量虽参与餐食分配，仍须与单独填写的零食合并考虑加餐额度。不要把同一份熟肉同时填入零食而重复扣除。

## 计算依据

- RER = 70 × 体重(kg)^0.75；健康成年猫维护期起点：已绝育 1.2 × RER，未绝育 1.4 × RER。任何计算只是起点，须根据体重、体况和实际响应与兽医调整。
- 餐食能量 = 每日目标 - 单独填写的零食 kcal；湿粮% = 100 - 干粮% - 鲜食%。三类按同一餐食能量分母分配，各自除以 kcal/g 得到 g/day。kcal/kg 除以 1000、kcal/100g 除以 100。
- 零食超过目标时阻止计算，修正提示使用未舍入目标；等于目标时明确警告三类餐食为 0 g、不是完整日粮。complete 模式仅零食超过目标 10% 提醒；topper 模式合并加餐比例 =（零食 kcal + 鲜食 kcal）/ 每日目标 × 100，超过 10% 提醒，等于不触发“超过”提醒。即使鲜食餐食占比不高，已有零食也可能占满额度。日常加餐尽量低于每日热量的 10%，这不是营养达标判断。
- 干物质数值换算 = as-fed % ÷ (100 - 水分%) × 100。仅作算术换算，不把保证分析 min/max 当作精确实测值，不判断营养达标。
- 显示值经过舍入，核心使用未舍入值；很小的正值用科学记数法避免显示为伪零。

## 数据与使用边界

计算器不按品牌自动填写数值，资料页另列四款已核对标签。不估算缺失的包装代谢能，不核验输入标签的真伪。能量匹配不能证明日粮完整、营养达标或鲜食配方安全。本工具不提供幼猫、孕哺、患病和减重治疗处方。

纯函数 API 保留原干湿粮调用：`calculate(input)` 未传 `freshPct` 时默认 0，未传 `freshType` 时默认 complete；显式空比例、非法类型、负数或非有限数值会报错。新增 `fresh` 与 dry/wet 同结构，以及 `wetPct`、`extraKcal`、`combinedExtraPct`、`extraWarning`；原 `treatPct` 含义不变。API 的 complete 是调用者对食品性质的声明，调用方负责事先核对包装；网页额外要求勾选确认，不把勾选当作营养认证。

输入仅在页面内存中处理，不上传、不主动保存，不使用 localStorage / sessionStorage。浏览器自身可能恢复表单，开始前请核对或重置；来源外链仅在主动点击时访问，不参与计算。
