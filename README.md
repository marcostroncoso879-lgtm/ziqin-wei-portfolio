# 魏子钦的个人主页

个人求职主页，包含研究经历、AI 工作方法和个人项目。

## 本地预览

在本目录运行 `python3 -m http.server 8767 --bind 127.0.0.1`，访问 `http://127.0.0.1:8767`。

页面使用原生 HTML、CSS、JavaScript，不需要安装前端依赖。所有资源随站点保存。

## 内容维护

- `index.html`：主页内容。
- `assets/styles.css`：响应式页面样式与打印样式。
- `assets/site.js`：手机导航、复制邮箱与打印。
- `projects/cat-food/`：爱猫如爱人的猫猫食物计算器，计算假设与来源见该目录说明。

硕士项目自 2026 年 1 月开始；本科毕设为 2025 年 2 月至 6 月。硕士预计 2027 年 6 月毕业。论文状态为录用待刊。

## GitHub Pages

使用仓库 `main` 分支的根目录发布。`.nojekyll` 保留静态资源原样输出；页面使用相对资源路径，可部署到 GitHub Pages 的项目子路径。
